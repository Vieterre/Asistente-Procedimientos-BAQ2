A1

Guía del flujograma

Use la simbología para representar la secuencia, decisiones y verificaciones del procedimiento.

Inicio / Fin

Inicio y fin

Marcan el primer evento identificable y el resultado verificable con el que concluye el procedimiento.

Actividad

Actividad

Describe una acción. Debe iniciar con un verbo en infinitivo y tener un responsable definido.

Decisión

Decisión

Formula una pregunta verificable y define rutas claramente rotuladas como Sí y No.

A→A

Conector

Permite continuar una ruta sin cruzar líneas ni perder la lectura del diagrama.

Línea de flujo

Indica el orden de ejecución entre los elementos y debe tener una única dirección de lectura.

Control

Punto de control

Complementa una actividad para validar, autorizar, comparar o verificar una condición crítica.

Registro

Registro o evidencia

Identifica el formato, documento o soporte que deja constancia de la actividad o control.

Secuencia completaTodo procedimiento debe tener un inicio y un fin identificables.
Decisiones verificablesLa pregunta de cada decisión se responde únicamente con Sí o No.
Ruta NoCuando una verificación no se cumple, debe indicar el ajuste requerido antes de repetir el control o finalizar por la ruta que aplique.
Control y evidenciaSon elementos complementarios: respaldan una actividad, pero no sustituyen el flujo principal.
A2

Criterios de evaluación

Rúbrica técnica vigente que utiliza el módulo de evaluación. Es de consulta: no modifica ninguna evaluación.

Verificaciones previas

  • Nombre: verbo en infinitivo, objeto y complemento cuando aplique.
  • Inicio: evento único, identificable; no una frase genérica.
  • Fin: resultado identificable y verificable.
